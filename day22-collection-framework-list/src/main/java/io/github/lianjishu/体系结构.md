```
Collection

│
└── Set（无序、不重复、无索引）
├── HashSet
│   └── LinkedHashSet
└── TreeSet
```

# 集合体系结构

## 1. 顶层结构
Java 集合体系主要分为两大分支（参考图1）：

*   **Collection**：单列集合
*   **Map**：双列集合

## 2. Collection 体系详细结构
根据图2，单列集合 `Collection` 主要分为 `List` 和 `Set` 两大家族：

### Collection
*   **List 系列集合**
    *   => `ArrayList`
    *   => `LinkedList`
    *   => `Vector`
*   **Set 系列集合**
    *   => `HashSet`
        *   => `LinkedHashSet` (它是 HashSet 的子类)
    *   => `TreeSet`

## 3. 集合特征对比
参考图2底部的总结：

> **List系列集合**：添加的元素是**有序、可重复、有索引**
> **Set系列集合**：添加的元素是**无序、不重复、无索引** (图中红框特别强调了 **无序**)
