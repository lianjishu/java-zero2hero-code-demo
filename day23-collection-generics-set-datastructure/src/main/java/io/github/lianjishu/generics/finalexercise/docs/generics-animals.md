# 泛型继承结构练习（动物 / 猫 / 狗）

> 本文档由习题截图整理而来，配套 `src/main/java/io/github/lianjishu/generics/exercise` 包下的练习使用。
> 本练习演示 **泛型通配符的上界（upper bounded wildcards）** 用法。

---

## 一、继承结构

```
                        Animal（动物）
                       /            \
                  Cat（猫）         Dog（狗）
                 /        \        /      \
            PersianCat   LiHuaCat  Teddy   Husky
             （波斯猫）   （狸花猫）（泰迪） （哈士奇）
```

> 说明：`Animal` 是最顶层父类；`Cat` 与 `Dog` 继承 `Animal`；波斯猫、狸花猫继承 `Cat`；泰迪、哈士奇继承 `Dog`。

---

## 二、属性 & 行为

所有动物都具备：

- **属性**
  - `name`（名字，`String`）
  - `age`（年龄，`int`）
- **行为**
  - `eat()`（吃东西）— 由各子类根据品种打印不同的内容

---

## 三、`eat()` 方法体打印内容

| 控制台输出                                          | 调用对象             |
| --------------------------------------------------- | -------------------- |
| 一只叫做XXX的，X岁的波斯猫，正在吃小饼干           | 波斯猫（PersianCat） |
| 一只叫做XXX的，X岁的狸花猫，正在吃鱼               | 狸花猫（LiHuaCat）   |
| 一只叫做XXX的，X岁的泰迪，正在吃骨头，边吃边蹭     | 泰迪（Teddy）        |
| 一只叫做XXX的，X岁的哈士奇，正在吃骨头，边吃边拆家 | 哈士奇（Husky）      |

> 提示：XXX = 该对象的 `name`，X = 该对象的 `age`。

---

## 四、测试类骨架

在测试类中定义如下方法用于"饲养"动物：

```java
public static void keepPet(ArrayList<???> list) {
    // 遍历集合，调用动物的 eat 方法
}
```

`???` 处的泛型通配符是本练习的核心，按下面的三种要求分别填写不同版本。

---

## 五、三个泛型要求

| 要求                                                                    | `???` 应填           | 解读                                               |
| ----------------------------------------------------------------------- | -------------------- | -------------------------------------------------- |
| **要求 1**：该方法能养所有品种的猫，但是不能养狗                        | `? extends Cat`      | 上界为 `Cat`，波斯猫/狸花猫可以，狗及其他动物都不行 |
| **要求 2**：该方法能养所有品种的狗，但是不能养猫                        | `? extends Dog`      | 上界为 `Dog`，泰迪/哈士奇可以，猫及其他动物都不行   |
| **要求 3**：该方法能养所有的动物，但是不能传递其他类型                  | `? extends Animal`   | 上界为 `Animal`，所有四种狗猫都可以，其他类型不行   |

> 共同点：三者都属于 **泛型上界通配符** `<? extends 父类>`，作用是限定集合中元素"必须是某个父类或其子类"。

---

## 六、推荐练习步骤

1. 在 `io.github.lianjishu.generics.exercise` 包下创建：
   - `Animal`（抽象类或普通父类，含 `name` / `age` / 抽象 `eat()`）
   - `Cat` 继承 `Animal`（可保留抽象 `eat()`，或提供猫的默认行为）
   - `Dog` 继承 `Animal`
   - `PersianCat`、`LiHuaCat` 继承 `Cat`，各自重写 `eat()`
   - `Teddy`、`Husky` 继承 `Dog`，各自重写 `eat()`
2. 编写 `Test.java`，提供三个 `keepPet` 重载/同名不同通配符版本，分别验证三条要求。
3. 在 `main` 里准备四个 `ArrayList`，分别装波斯猫、狸花猫、泰迪、哈士奇，依次调用三种 `keepPet`，观察编译期是否报错。

---

## 七、易错点提示

- `<? extends Cat>` 只保证"取出来一定是 `Cat`"，**不能往里 `add`** 除了 `null` 之外的任何元素（编译会拒绝）。
- 如果你还需要在方法内 `add` 新元素，应该用 `<? super Cat>`（下界），但本练习限定为养动物（只读遍历），所以选择上界。
- 第三种要求 "能养所有动物" 是 `Animal` 的子类（猫/狗/波斯猫/泰迪……）都可以，但**不是动物的类传不进来**——这就是 `extends` 上界的作用。
